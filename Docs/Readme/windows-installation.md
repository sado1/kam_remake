# Game installation on Windows PC

- To run the Remake, you will need to own the original `Knights and Merchants: The Peasants Rebellion` game. If you don't have it, you could buy it on Steam, GOG or other platforms, or use your old installation CD. 
> [!IMPORTANT]
> If you have KaM TPR **Steam** version, you **have to** run the original game at least **once**!
> Otherwise, KaM Remake installer will not detect your original game installation.
- You have to download installation exe file, f.e. `KaM Remake Beta r15122.exe` and run it. 
- Installer asks you about preferred installation language, then tries to detect if you have game installed on your computer. 
- Choose installation directory. It should be a separate directory, don't install into the original game's directory.
- OpenAL is required for sound to work properly. The installer will ask, if you want it to be automatically installed.
- That's it, now you can run the game :)

Good luck!
