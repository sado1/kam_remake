## On windows

Game installation on Windows is quite simple. 

- You have to download installation exe file, f.e. `KaM Remake Beta r15122.exe` and run it. 
- Installer asks you about preferred installation language and then try to detect if you have the original `Knight and Merchants: The Peasants Rebellion` game installed on your computer. If you don't have it you could buy it on Steam, GOG or other platforms, or use your old installation CD. 

| ℹ️ **Notice** |
|-----------------------|
|You have to run KaM TPR **Steam** version at least **once**|

_If you have KaM TPR steam version, you have to run original game at least once, to make it possible for KaM Remake installer to detect your original game installation_

After that choose installation directory. It should be separate directory, don't install into original game directory. 
You can install different KaM Remake versions, but they has to be in the different directories.

After installation is complete you can run and enjoy the game. 

Good luck!
